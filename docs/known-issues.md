## 已在源码修复

- 共享严格配置校验，关机余量必须覆盖通知与收尾预算，错误类型的超时参数返回明确配置错误；所有运行期限使用单调时钟；NTP 优先，拒绝用错误年份的 RTC 覆盖系统时间，写回 RTC 后核验误差。
- 任务后按关机余量重新计算闹钟，验证 UTC 时分、repeat 和 enabled；超过 24 小时的 DST 间隔限制到目标 UTC 星期，避免提前一天响铃；PiSugar 瞬时读写错误最多尝试 5 次，恢复就绪、校时与闹钟最多 5 轮，受同一总预算限制。
- 秋季回拨期间按实际秒数计算关机余量，避免本地时间加法跳过计划或重置 fold；校时后按单调时钟耗时修正事件开始时间，最终结束时间覆盖通知和关机收尾。
- 任务和通知使用进程组超时；健康检查、启动异常、磁盘/通知/显示失败进入统一收尾。systemd 提供 300 秒与失败关机兜底，DEBUG 为显式例外。
- 通知接口具备次数、单次和总时限；状态持久化及末尾错误显示接口已接入，具体通知通道和 UI 尚未配置。关机请求首次失败会在原通知期限内通知，且不会误记为已恢复。
- Python 采集替换脆弱的 Shell 解析；单指标失败不阻断其他指标和屏幕，缺失值不会写成 I/O 错误文本，显示失败返回非零。
- 4 bpp 清屏正确复制像素位，绘图拒绝等于宽高的坐标；驱动 busy/display-ready 有期限，信号处理只设置取消标记。
- 网络、socket、显示及状态路径统一到配置；状态使用带 UTC 偏移的时间戳，电池显示消费同一份样本；日志在应用内按 1 MiB、4 个备份轮换。CSV 与 ping 采集已移除。
- 提供 PiSugar 本地控制 drop-in：关闭不需要的 TCP/独立 WS，HTTP 仅监听回环，UDS 权限 660；不覆盖包管理 unit，已在当前 Pi 安装并读回核验。

- 常驻服务提供设备 token 认证、管理员登录、内容编辑、当前周期远程 debug、SQLite 历史与超期未报到标记；有界 HTTP 和持久队列替代固定 IP ping。详见 [服务指南](server.md)。
- 能耗预测对密集采样使用短时滚动中位数识别持续回升，避免电量低读数后的回弹不断重置放电段、导致已有大量样本仍不显示预测。突发高读数先暂停预测，恢复后保留原观察历史；持续回升仍重新积累数据。2026-10-25 已通过 191 项离线测试，并在管理中心核验 113 个周期、约 56 小时的历史可输出估算；现有历史和设置保留，未改动树莓派。
- 电子纸使用 server 的 ASCII 标题、状态和六条信息；Python 与 C 均校验，C 在硬件初始化前拒绝非法内容。任务为 RTC 阶段预留 60 秒工作预算。
